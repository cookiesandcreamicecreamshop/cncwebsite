# Photos

Drop your photos into this folder (`assets/photos/`) using **exactly** these file names.
Each one replaces its "photo here" placeholder on the site automatically. Until a file is
there, the drawn placeholder shows instead, so you can add them one at a time.

- Use `.jpg` files, about 1200-1600 px on the long side (under ~500 KB each loads fast).
- Photos are cropped to fill their frame, so keep the subject near the middle.
- File names are lowercase with dashes; they must match exactly.
